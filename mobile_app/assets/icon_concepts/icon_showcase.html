🚀 How to apply the "Attendee" icon to your Flutter Mobile App

To configure Attendee as your official launcher icon, add this to your mobile_app/pubspec.yaml: 

# 1. In mobile_app/pubspec.yaml under dev_dependencies:
dev_dependencies:
  flutter_launcher_icons: ^0.13.1

flutter_launcher_icons:
  android: "launcher_icon"
  ios: true
  image_path: "assets/icon_concepts/attendee_app_icon_1024.png"
  adaptive_icon_background: "#0F172A"
  adaptive_icon_foreground: "assets/icon_concepts/attendee_app_icon_1024.png"

# 2. Run in the mobile_app directory:
flutter pub get
dart run flutter_launcher_icons
